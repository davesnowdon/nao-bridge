# API coverage

The routes below use the `/api` prefix. Request and response names refer to the
canonical [OpenAPI and named schemas](../contracts/README.md). Each listed Python
namespace is available on `Nao` and `AsyncNao`. Created activity handles expose
read-back and cleanup, while `Operation` handles cover finite command outcomes.
Browser and non-Python clients can follow the same lifecycle over HTTP/SSE.

| Surface | HTTP paths and schemas | Python API | Events, availability and verification |
| --- | --- | --- | --- |
| Discovery and state | `/robot`, `/robot/capabilities`, `/state`, `/robot/diagnostics` · `Robot`, `Capabilities`, `State`, `Diagnostics` | `robot.info`, `robot.capabilities`, `robot.state`, `robot.diagnostics` | Connection and capability changes carry bridge/generation identity. State reports age and quality per group. `test_contract`, `test_http`, `test_observations`. |
| Sessions and operations | `/sessions` and its renew/close/revoke routes, `/operations` and its `/cancel` route, `/robot/stop` · `Session`, `Operation`, `OperationPage` | Context-managed client session, `operations.get`, `operations.list`, `Operation.cancel`, `robot.stop`. Explicit revoke is an operator HTTP/Swagger procedure. | `session.changed` and `operation.changed`. Conflicting reservations return `resource_busy`. Unknown native outcomes retain ownership; unretained IDs can return 404. `test_clients`, `test_recovery`, `test_client_failures`, `test_replacement`. |
| SSE | `/events/types`, `/events/subscriptions`, subscription state and `/stream` · `SubscriptionCreate`, `Subscription`, `Event` | `events.types`, `events.subscribe`, subscription iteration and close | `stream.ready`, `stream.reset`, `state.sample`. Reconnect resets without replay. Admission is bounded and a blocked viewer can lose continuity. `test_http`, `test_sampling`, `test_raw_http`, SDK `test_sse`, native soak. |
| Contact and passive sensor state | `/sensors`, `/state?include=sensors` · `Sensors`, `State` | `sensors.list`, `sensors.state` | `touch.changed` covers named head, hand and foot contacts. Catalog/state distinguish unavailable channels, including inertial and foot-load readings. `test_observations`, native contact fixtures and the [increment 1 results](implementation-status.md). |
| Sonar and thresholds | `/sensors/observers` and its resource/stop routes, `/events/subscriptions` · `SensorObserver`, `ThresholdRule` | `sensors.observe`, `sensors.get_observer`, `events.subscribe` with thresholds | `sensor.observer_changed`, `sensor.threshold_changed`. Sonar requires explicit shared demand; stale or unavailable data resets the threshold baseline. `test_sonar`, `test_sensor_observers`, `test_thresholds`, `test_client_sensor_observers`. |
| Joint and posture discovery | `/motion/joints`, `/motion/postures`, `/state?include=joints,motion` · `Joints`, `Postures`, `State` | `motion.joints`, `motion.postures`, `motion.state` | Joint values distinguish measured, commanded and stiffness. Posture and fall events depend on native support. `test_motion`, `test_observations`, SDK `test_sse`. |
| Motion preparation | `/motion/wake`, `/motion/rest`, `/motion/stiffness_changes`, `/motion/posture_changes` · `MotionTransitionCreate`, `StiffnessCreate`, `PostureCreate` | `motion.wake`, `motion.rest`, `motion.set_stiffness`, `motion.posture` | Operation and observed state are independent. Native readiness and joint/coupling validation precede dispatch. `test_motion`, `test_raw_http`, Recorder and presentation workflows. |
| Finite joint commands and trajectories | `/motion/joint_moves`, `/motion/trajectory_runs` · `JointMoveCreate`, `TrajectoryRunCreate`, `Trajectory` | `motion.move_joints`, `.head`, `.hand`, `.play`, portable `Trajectory` | Explicit axes and absolute units. Scoped replacement waits for confirmed stop. Stale motion state and invalid limits fail admission. `test_motion`, `test_replacement`, `test_recorder_example`, SDK `test_trajectory`. |
| Joint setpoints | `/motion/joint_setpoints` · `JointSetpoint`, `Operation` | `motion.set_joint_targets`, `motion.joint_control` | Ordered updates share an operation; duplicates do not renew expiry. Unconfirmed hold remains quarantined. Hardware dispatch is gated. `test_joint_controls`, `test_client_controls`, native watchdog tests. |
| Finite walking and odometry | `/motion/moves`, `/state?include=motion` · `MoveCreate`, `State` | `motion.move`, `motion.odometry` | Availability requires native locomotion and fresh motion state. Odometry is generation/origin scoped. `test_walk_api`, `test_locomotion`, `test_wanderer_example`. |
| Velocity and priority motion stop | `/motion/velocity`, `/motion/stop` · `VelocitySetpoint`, `MotionStopRequest` | `motion.set_velocity`, `motion.velocity`, `motion.stop` | Velocity reservation expires independently of the HTTP session; hardware velocity is gated. Scoped stop bypasses ordinary command workers and reports uncertain results. `test_velocity_api`, `test_velocity_adapter`, `test_motion_stop`, native occupied-worker tests. |
| Gestures | `/motion/gestures`, `/motion/gesture_runs` · `GestureCatalog`, `GestureRunCreate` | `motion.gestures`, `motion.gesture`, `actions.gesture` | Wave, point, nod and shake use explicit resource variants with fresh measured starts. Physical dispatch is gated. `test_gestures`, `test_sequences`, native conformance. |
| Speech and vocabulary | `/speech/options`, `/speech/utterances`, `/speech/listeners` and configuration/stop resources · `SpeechOptions`, `SpeechCreate`, `Listener` | `speech.options`, `speech.say`, `speech.listen`, `speech.get_listener`, `Listener.configure`, `.stop` | Readiness and pause state are observable through `speech.listener_changed`. Hypotheses arrive on `speech.recognized`. Speech and playback reserve the same output. Animated speech remains fixture-gated. `test_speech_options`, `test_listeners`, `test_client_listeners`, `test_recognition`. |
| Lights | `/lights`, `/state?include=lights`, `/lights/transitions` · `LightCatalog`, `State`, `LightTransitionCreate` | `lights.groups`, `lights.state`, `lights.set` | Observed channels arrive in shared state/SSE; availability depends on native groups. Overlapping groups conflict. `test_lights`, native conformance and presentation. |
| Autonomy and profiles | `/state?include=autonomy`, `/autonomy/transitions`, `/autonomy/profiles`, `/autonomy/profile_runs` · `AutonomyStateValue`, `AutonomyTransitionCreate`, `AutonomyProfileCatalog`, `AutonomyProfileRunCreate` | `autonomy.state`, `.configure`, `.profiles`, `.apply` | `autonomy.changed`. Strict admission by default, explicit partial application, opt-in restore of eligible settings on the same generation. `test_autonomy`, `test_raw_http`, Recorder and Wanderer workflows. |
| Installed behaviors | `/behaviors`, `/behaviors/runs` · `BehaviorPage`, `BehaviorRunCreate` | `behaviors.list`, `behaviors.run` | `behavior.changed`; discover installed names before dispatch. Physical execution remains gated. `test_behaviors`, native conformance. |
| Passive vision | `/vision/observers` and its resource/stop routes · `VisionObserverCreate`, `VisionObserver` | `vision.observe`, `vision.get_observer` | `vision.detections` and `vision.observer_changed`. One of face, NAOmark and people per observer. Native service discovery and compatible camera/settings determine availability. `test_vision_observers`, `test_face_adapter`, native conformance. |
| Head-only face tracking | `/vision/trackers` and its resource/stop routes · `VisionTrackerCreate`, `VisionTracker` | `vision.track`, `vision.get_tracker` | `vision.tracker_changed`, exact head reservation and native stop confirmation. Physical tracking remains gated. `test_face_tracker`, native occupied-worker tests. |
| Camera catalog and stills | `/vision/cameras`, `/vision/captures` · `Cameras`, `CameraCaptureCreate`, `Operation` | `vision.cameras`, `vision.capture` | `operation.changed`, `asset.created`. Still metadata identifies camera and acquisition times. Camera conflicts and storage failures are explicit. `test_vision`, `test_camera_adapter`, `test_wanderer_example`. |
| Camera preview | `/vision/previews` and resource, content and stop routes · `CameraPreviewCreate`, `CameraPreview`, multipart JPEG | `vision.preview`, `vision.get_preview`, `CameraPreview.frames`, `.stop` | Read-back via GET. Matching settings share acquisition; one viewer can detach without stopping the feed. Conflicting settings return `resource_busy`. `test_client_previews`, `test_video_recordings`, native conformance. |
| Samples, video and microphone recordings | `/recordings` and resource/stop routes · `RecordingCreate`, `Recording`, `RecordingLine` | `recordings.start`, `.samples`, `.camera`, `.microphone`, `.get`, `Recording.stop` | `recording.changed`, `asset.created`. Shared state sampling or native acquisition; finalization and partial errors stay visible. Reserved bytes and media formats are capability-dependent. `test_recordings`, `test_video_recordings`, `test_audio_recordings`, native restart and soak. |
| Retained assets and WAV output | `/assets`, asset resource/content routes, `/audio/playbacks` · `Asset`, `Assets`, `AudioPlaybackCreate` | `assets.list`, `.get`, `.download`, `.delete`, `.upload`; `audio.play` | `asset.created`, `operation.changed`. Content type, size, checksum, ranges and ETags are verified. Active readers/playback pin content. Quota exhaustion returns 507. `test_assets`, `test_audio_uploads`, `test_audio_playback`, Recorder workflow. |
| Server-side sequences | `/sequences/schema`, `/sequences/validate`, `/sequences/runs` · `SequenceDocument`, `SequenceValidation`, `Operation` | `sequences.schema`, `.validate`, `.run`, pure `actions`, `sequence` and `parallel` | Parent and child `operation.changed` events, paginated child results, fail-fast sibling cancellation and uncertainty fencing. Invalid plans fail before dispatch. `test_sequences`, `test_presentation_example`, portable raw conformance. |

with OpenAPI. The SDK tests exercise the two client styles through HTTP/SSE;
the direct runner exercises lifecycle and workflow behavior independently of
those clients. Fixture evidence and physical acceptance are tracked separately.
